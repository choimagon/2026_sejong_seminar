# 수업 진행 안내

환경 설치는 수업 전 완료합니다. [번호별 파일·명령·XML](../examples/README.md)을 기준으로 진행합니다.

| 구간 | 시간 | 진행 |
| --- | --- | --- |
| 전반 | 5분 | show.py 실행과 실제 창에서 카메라 조작 |
| 전반 | 10분 | 01 move 함수와 바퀴 움직임 |
| 전반 | 10분 | 02 키 연결·키 문자 변경·중앙 기둥 통로 운전 |
| 전반 | 20분 | 03 시간 기반 기둥 우회, 04 반대 경로 비교 |
| 전반 | 5분 | 결과 비교와 센서 필요성 연결 |
| 휴식 | 10분 | 쉬는 시간 |
| 후반 | 8분 | 초음파·라이다 설명과 실제 XML의 차이 |
| 후반 | 7분 | 05·06 센서 출력 형태와 실제 GUI 관찰 |
| 후반 | 20분 | 07 거리 조건문 작성, 08 대체 센서 비교 |
| 후반 | 8분 | 09·10 직접 운전·측정점 누적 지도 |
| 후반 | 7분 | 11 작은 미로 제공 데모·정리 |

학생이 직접 작성하는 핵심은 01의 바퀴 속도, 02의 키 연결, 03의 행동 순서, 07의 조건문입니다.
비교 파일을 전부 새로 입력하는 과제로 만들지 않습니다. 진도가 늦으면 비교 경로·대체 센서는 강사 화면으로 보여줍니다.
PPT에는 시간 배분 대신 준비·실습 번호를 표시하며 운영 시간은 강사 노트에만 둡니다.
